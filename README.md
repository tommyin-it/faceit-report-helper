# FACEIT Report Helper

Publiczne repozytorium gotowych wydań rozszerzenia Chrome. Kod źródłowy nie jest
publikowany w tym repozytorium.

## Instalacja

1. [Pobierz najnowszy plik `faceit-report-helper.zip`](https://github.com/tommyin-it/faceit-report-helper/releases/latest/download/faceit-report-helper.zip).
2. Rozpakuj ZIP do stałego katalogu.
3. Otwórz `chrome://extensions` i włącz **Tryb dewelopera**.
4. Kliknij **Załaduj rozpakowane** i wskaż katalog zawierający `manifest.json`.

Do instalacji i aktualizacji nie są potrzebne Node.js ani npm. ZIP zawiera
wyłącznie gotowe pliki rozszerzenia z katalogu `dist`.
